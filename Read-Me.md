# Remember the Shape

## Technologies Used
1. HTML
2. CSS
3. Javascript

## Description
Remember the Shape is a memory game that presents a set of shapes in a specific sequence to the user once the game is started for 3 to 4 seconds and then will be presented with all the shapes which will need to be clicked in the correct order of the sequence they were presented at the start. 

The game will gradually get harder as the user completes a level. Starting the game with 2 shapes to remember, with 5 shapes to select from. As the user moves ahead in the game, the sequence gets longer and more shapes get added to the selection.

The aim of the game is to challenge the user's memory by seeing how far can they go.

## User Stories
1. As a user, I want to see a start menu with a Title, a start button and instructions giving me a brief of how the game works on the menu.

2. I want to see a countdown before the sequence is presented to me.

3. I want to see the timer during the presence of the sequence.

4. I want to see the shapes show up on the screen after the timer expires.

5. I want to see the level I reached to from start and as I progress.

6. I want to see a "win" message/indicator when I get a sequence correct before moving on to the next level.

7. I want to see my record/score after losing.

8. I want to play again after losing. Return to main menu button or Try Again button
